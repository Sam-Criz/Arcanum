# TDD Engine
## Instruções
- Sempre que uma nova funcionalidade matemática ou de combate for solicitada, gere primeiro o arquivo de teste usando o runner nativo do Node.js.
- Escreva testes cobrindo limites críticos (ex: dano que deixa o NPC com menos de 0 PV, acúmulo de condições contínuas (DoT) e resoluções de armadura RD).
- Garanta que o código sugerido passe perfeitamente nas suítes descritas.
