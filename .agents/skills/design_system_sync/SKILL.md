# Arcanum Design System & Layout Fixes
- **Remoção do Roxo:** Substitua qualquer fundo azul escuro ou arroxeado em painéis por `#1a1816` (papel) ou `#131211` (tinta).
- **Centralização do Dock:** A barra de ações inferior (`Dock Tático`) deve usar estritamente `flex justify-center items-center mx-auto w-full max-w-4xl`.
